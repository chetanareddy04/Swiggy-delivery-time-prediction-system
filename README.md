# Swiggy-delivery-time-prediction-system

A Machine Learning project that predicts estimated food delivery time based on order details and delivery-related factors, with an interactive Streamlit web application.

###  CRISP-ML(Q) Methodology

* **Business & Data Understanding:** Identified the delivery-time prediction problem and explored the dataset.
* **Data Preparation:** Handled missing values, cleaned data, and performed feature engineering.
* **Model Engineering:** Built an XGBoost Regressor pipeline and applied K-Fold Cross-Validation and RandomizedSearchCV for hyperparameter tuning.
* **Model Evaluation:** Evaluated performance using the R² score and compared training and testing results.
* **Deployment:** Developed an interactive Streamlit application to generate delivery-time predictions.
* **Quality Assurance:** Identified future opportunities for model monitoring and improvement.

### Tech Stack

`Python` `Pandas` `NumPy` `Matplotlib` `Seaborn` `Scikit-learn` `XGBoost` `Streamlit`
